001-econsult-flow · lets-implement

E-consult submission in the app

One complete e-consult path a patient can finish in under two minutes, with every real state (loading, empty, error, sending, offline, partial photo failure), usable with screen readers and the largest text sizes, in a repository a reviewer runs from a clean clone with npx expo start.

Three steps plus a confirmation on an expo-router native stack: recipient, practice questions (skipped when none), message with an optional downscaled photo. TanStack Query over a typed fake transport with zod contracts, offline-first reads and a fail-fast send; expo-image-picker plus expo-image-manipulator; core React Native accessibility and keyboard handling only.
