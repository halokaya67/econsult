Re-check · T016

Header “Home” control at the largest text size

The Recipient step’s header button was previously clipped to about half its glyph height at the largest Dynamic Type setting, because the native navigation bar keeps a fixed height while the label kept scaling. The fix caps that one button’s font scaling at 1.3×, mirroring iOS’s own bar buttons.
